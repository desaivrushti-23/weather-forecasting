# 🌦️ Weather Dashboard Analysis

## 📌 Project Overview
This project is a Weather Dashboard developed using **Python** and **Power BI**. It collects weather data, performs data cleaning and analysis, and presents interactive visualizations to understand weather patterns across different cities.

The dashboard provides real-time weather insights along with historical sample data analysis using charts, KPIs, and filters.

---

## 🎯 Objectives
- Collect weather information using Python.
- Clean and preprocess weather data.
- Analyze weather trends.
- Create interactive Power BI dashboards.
- Visualize important weather metrics.

---

## ▶️ How to Run

### 1. Clone Repository

```bash
git clone https://github.com/yourusername/Weather-Dashboard.git
```

### 2. Install Libraries

```bash
pip install -r requirements.txt
```

### 3. Run Streamlit App

```bash
streamlit run app.py
```
